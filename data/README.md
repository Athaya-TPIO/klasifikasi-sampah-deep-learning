# Dataset TrashNet

Sumber: https://github.com/garythung/trashnet (Gary Thung & Mindy Yang).

**Dataset tidak disertakan dalam repositori ini.** Gunakan file ZIP versi `dataset-resized` dari sumber asli. File yang sebelumnya dipakai pada eksperimen ini bernama `TrashNet, Garbage Classification.zip` dan berisi struktur folder `dataset-resized/{cardboard,glass,metal,paper,plastic,trash}/`.

Di Google Colab, notebook akan meminta file ZIP jika tidak ada di `/content/TrashNet, Garbage Classification.zip`. Tidak perlu mengekstrak ZIP manual; notebook akan menanganinya.

Pembersihan pada eksperimen: 2.527 gambar valid awal, tiga pasangan gambar identik berlabel berbeda (6 berkas) dikeluarkan, tersisa 2.521 gambar. Split stratified seed 42: 2.016 train, 252 validation, 253 test.

**Atribusi dan hak pakai:** cantumkan sumber TrashNet dan teliti ketentuan lisensi berkas dataset yang digunakan, terutama sebelum penggunaan atau distribusi di luar keperluan akademik.
