# Model hasil pelatihan

- `trashnet_mlp.keras` — baseline MLP, test accuracy 19,37%.
- `trashnet_cnn.keras` — baseline CNN, test accuracy 70,75%.

Keduanya merupakan hasil eksperimen UTS pada data uji 253 gambar. Jangan menganggap hasil ini jaminan akurasi di lingkungan nyata.

**Catatan unggah GitHub:** model MLP sekitar 38 MB dan melampaui batas 25 MB per berkas bila diunggah melalui antarmuka web GitHub. Gunakan perintah Git lokal untuk mengunggah repositori lengkap, atau unggah notebook tanpa bobot model dan tautkan hasil unduh terpisah.
